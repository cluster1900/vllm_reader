# 全书符号普查记录（2026-11-10）

本记录是 `glossary/notation.md`（F0）的输入：在改任何章节之前，把十章里每个公式和短代码样式符号用到的字母查一遍，
找出“一个字母多种意思”和“一个量多种写法”。结论落在 `glossary/notation.md` 的符号表和改名对照表里，本文件只留证据。
追踪 issue：cluster1900/bot-hub#128。

## 范围与方法

- 版本：vllm_reader main `14708f03`（#20 合入之后）；源码引用的 pin 仍是 `05caae03c20f69436ff7ec23ded339ea104f1a01`。
- 对象：`book/*/README.md` 十章。没有改动任何章节正文。
- 公式：用 `scripts/math_support.markdown_formulas`（与 `check_book.py` 同一个扫描器）取出全部 `$…$` 与 `$$…$$`，
  逐个拆成“字母或希腊字母 + 下标/上标”的符号，描述性下标（`\mathrm{…}`）保留在符号里，`\operatorname`、`\mathrm{TTFT}` 之类的名字整体计一个。
- 代码样式符号：行内代码里像符号的短片段（单个字母、`Hq`、`H_kv`、`[B,S,Hq,Dh]` 这类形状）；围栏代码块不计。
- 另外人工补查了三类扫描器看不到的写法：行内代码里的算式（`T>0`、`R=127`、`Dout/p`）、mermaid 标签里的符号
  （`sqrt Dh`、`tokens 0 到 B-1`、`c+n < T ?`）、正文里夹在中文句子里的字母。前两类已并入改名对照表；
  第三类（例如“块大小 B”）没有可靠的自动办法，改名对照表里注明了，由各批次改写时再读一遍。
- 复现：`python3 scripts/notation_census.py --code`（下面两张表就是它的输出）。

## 结果

公式 403 个（01:71、04:102、05:12、06:44、07:31、08:10、09:94、10:39）；LaTeX 符号 289 种；代码样式符号 96 种。

1. **一个字母多种意思**（普查前）：`T`（token 数、温度、block 大小、耗时、转置）、`B`（批大小、block 大小、字节数、token 预算、布尔量、
   all-reduce 块大小）、`N`、`L`、`P`、`I`、`O`、`M`、`R`、`W`、`p`、`d`、`m`、`S`、`H`、`V`、`Q` 等 20 来个字母，
   逐项见 `notation.md` 第 4 节。同一章内部的同义写法也有：ch04 的 $N_{\mathrm{target}}$ / $N_{\mathrm{tokens}}$ / `T`，
   $N_{\mathrm{computed}}$ / `c`，$N_{\mathrm{placeholders}}$ / `P`。
2. **同一个量多种写法**：单头宽度（`D_h`、`D_head`、`d`、`D_v`）、block 大小（`T`、`B`、`block_size`）、滑窗 `n_null` 公式（ch05 与 ch06 同式两写）、
   可给 KV 的显存预算（ch07、ch08、ch05 三处，`=` 与 `≈` 并存）、KV head 数（`H_kv`、`H_k/H_v`、`H_kv,local`）。
3. **tracker 清单之外，这次普查新发现**：
   - ch03 L624–625、ch08 L287 的 `P` 是 PP stage 数，与 ch04 的 `P`（placeholder）、ch09 的 `P`（PCP 大小）撞名，改 $\mathrm{PP}$；
   - ch06 L316–318、L348、L365 用 `A`、`K`、`r`、`m` 表示 manager block 大小、kernel block 大小、两者之比与 manager block ID，
     分别与矩阵 $A$/$K$、请求下标 $r$、同章在线 softmax 的 $m$ 冲突；
   - ch01 L324、L334 的 `M`（causal mask）与全书 $M_{\dots}$（显存、字节数）冲突；
   - ch01 L263 的 `I`（MLP 中间宽度）与 ch04、ch09 的 `I` 冲突；
   - ch01 L891 的实验常量 `P=128`、`G=32` 与 `P`、ch10 的 goodput $G$ 冲突；
   - ch10 L909–911 的 Little 定律 `L=λW`：`L` 是层数、`W` 是 world size；
   - ch09 同一章里 $n_i$ 有两个意思：L693 的 logits 行数、L1060 的路由到 expert rank 的 token 数；ch09 通用线性层的权重 `A` 与 `W` 的分工；
   - 行内代码里的算式也带着旧符号：ch01 L513–L553、ch07 L1104–L1105 的 `T>0`/`T=0`，ch09 L444、L488 的 `Dout/p`，ch05 L1651–L1659 的 `R`、`T`、`p`；
   - 全局符号与局部字母的撞名（F0 r1 评审指出，r2 已改）：`ℓ`（ch09 本机 rank 与 ch06 在线 softmax 分母，后者改 $Z$）、`Q`（Query 矩阵与 ch09、ch10 的吞吐，后者改 $\mathrm{thr}$）、
     `θ`（RoPE 旋转角，只在第 1 节登记，不再列为局部）、`b`（ch06 物理 block ID、ch09 偏置 $b_i$、ch10 burstiness，三者都是局部字母，不再写成全局）。
4. **普查后保持不变的**：索引（$i,j,r,t$，局部）；ch10 的 $\lambda$、$\rho$、$G$ 等已经统一的量；
   ch09 的全局 rank $g$ 与本机 rank $\ell$（$\ell$ 是全局符号，ch06 的 $m,\ell$ 因此改为 $m,Z$）、局部的 $\alpha,\beta$；$H_{\mathrm{kv,local}}$、$\mathrm{TP}$ 等；
   ch01 的 `n`（`SamplingParams.n`，API 参数）。它们要么已经满足“一字母一义”，要么是小节内的局部字母（`notation.md` 第 3 节）。
   ch10 的 $Q_{\mathrm{out}}$、$N_{\mathrm{GPU}}$、$N_{\mathrm{users}}$ 原先看似统一，但与 Query 矩阵 $Q$、“$N$ 是 token 数”冲突，所以也在改名对照表里（$\mathrm{thr}$、$n_{\mathrm{GPU}}$、$n_{\mathrm{users}}$）。
